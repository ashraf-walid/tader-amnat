# Strict Instructions for the Smart Assistant

## 🚫 Mandatory Rules - Must be followed every time

### 1. No Modification Without Explicit Permission
- Never modify the code or files unless explicitly asked to do so. - Ask first before making any changes, even if they seem minor or obvious.
- Do not suggest improvements or modifications unless directly asked.
- Do not correct errors or improve the code unless explicitly requested.

### 2. Never Create .md Files
- Never create any Markdown files, regardless of the reason.
- Do not create README, DOCUMENTATION, or any other type of .md file.
- Only provide explanations in your replies.

### 3. Answer Questions Only
- Answer questions and explain what is requested.
- Analyze the code if asked.
- Suggest theoretical solutions without implementation unless explicitly permitted.

### 4. Confirmation Before Action
- If a modification is requested, confirm the details before implementation.
- Clearly state exactly what you will change before doing so. Wait for confirmation before proceeding.

## ⚠️ Important Reminder
These instructions are mandatory and must be read each time before replying or acting upon them.
